# raf-effect-atom on React Router Framework Mode

> A standalone copy of [`examples/react-router`](https://github.com/KATT/raf-effect-atom/tree/main/examples/react-router), generated for CodeSandbox from every push to `main`: edit the original, not this copy. The app is in `apps/react-router`; the libraries, and the UI, fake database and RPC backend it shares with the other examples, are in `packages/`.

The issue tracker on React Router Framework Mode: atoms started from server loaders and streamed into the browser, over Effect RPC served from a resource route. It runs live at <https://react-router.raf-effect-atom.katt.dev>, and [the docs](https://raf-effect-atom.katt.dev/docs/examples) list what each screen shows.

## Run it

[Open it in CodeSandbox](https://codesandbox.io/p/devbox/github/KATT/raf-effect-atom/tree/codesandbox/examples/react-router?file=/apps/react-router/app/routes/prefetch/issues.tsx), or locally:

```shell
pnpm install
pnpm dev
```

Then open <http://localhost:3006>.
