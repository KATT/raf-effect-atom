# raf-effect-atom on TanStack Start

> A standalone copy of [`examples/tanstack-start`](https://github.com/KATT/raf-effect-atom/tree/main/examples/tanstack-start), generated for CodeSandbox from every push to `main`: edit the original, not this copy. The app is in `apps/tanstack-start`; the libraries, and the UI, fake database and RPC backend it shares with the other examples, are in `packages/`.

The issue tracker on TanStack Start: atoms started from route loaders and streamed into the browser, over Effect RPC served from a server route. It runs live at <https://tanstack-start.raf-effect-atom.katt.dev>, and [the docs](https://raf-effect-atom.katt.dev/docs/examples) list what each screen shows.

## Run it

[Open it in CodeSandbox](https://codesandbox.io/p/devbox/github/KATT/raf-effect-atom/tree/codesandbox/examples/tanstack-start?file=/apps/tanstack-start/src/routes/prefetch/issues/index.tsx), or locally:

```shell
pnpm install
pnpm dev
```

Then open <http://localhost:3005>.
