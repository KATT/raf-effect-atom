# raf-effect-atom on the Next.js App Router

> A standalone copy of [`examples/nextjs`](https://github.com/KATT/raf-effect-atom/tree/main/examples/nextjs), generated for CodeSandbox from every push to `main`: edit the original, not this copy. The app is in `apps/nextjs`; the libraries, and the UI, fake database and RPC backend it shares with the other examples, are in `packages/`.

The issue tracker on the Next.js App Router: atoms started in server components and streamed into client components, over Effect RPC served from a route handler. It runs live at <https://nextjs.raf-effect-atom.katt.dev>, and [the docs](https://raf-effect-atom.katt.dev/docs/examples) list what each screen shows.

## Run it

[Open it in CodeSandbox](https://codesandbox.io/p/devbox/github/KATT/raf-effect-atom/tree/codesandbox/examples/nextjs?file=/apps/nextjs/src/app/prefetch/issues/page.tsx), or locally:

```shell
pnpm install
pnpm dev
```

Then open <http://localhost:3007>.
