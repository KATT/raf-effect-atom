# Logo (human asked, agent designed)

- Human: a new logo for this repo, not raf-query's.
- **The mark**: a near-black tile (`#0B0B14`, Effect's monochrome look) with a white "r" (render) inside a tilted electron orbit (an atom), drawn as a teal → violet gradient (`#2DD4BF` → `#A78BFA`); the electron at the orbit's top right is a request in flight. Checked legible from 256 px down to a 16 px favicon, on light and dark backgrounds.
- The file is `www/public/favicon.svg`, used by the root README and, once they exist, the docs site and the example apps. If an app needs it as a string (Next and Vite import static files differently), keep that copy identical.
- Lost: raf-query's gradient tile (would read as the same project); a plain "r" without the orbit (loses the Atom half of the name).
