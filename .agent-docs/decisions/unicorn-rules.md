# Unicorn rules: bug catchers and modern APIs, nothing that fights Effect (human asked, agent picked)

- Human: add a curated set of oxlint `unicorn` rules. The agent picked them from the 138 that oxlint 1.89 supports (`oxlint --rules`). `correctness` and `suspicious` are on as categories, so their unicorn rules (`no-thenable`, `no-await-in-promise-methods`, `no-array-sort`, `no-instanceof-builtins`, `require-post-message-target-origin`, …) were already on; the picks come from `style`, `pedantic`, `restriction` and `perf`. File names are [file-names.md](./file-names.md).
- **Kept from raf-query**: the 30 listed in `.oxlintrc.json` before this decision (`catch-error-name`, `prefer-at`, `prefer-node-protocol`, `prefer-top-level-await`, …).
- **Added, catches bugs**: `new-for-builtins` (`Date()` is a string), `no-negation-in-equality-check`, `no-object-as-default-parameter`, `no-new-buffer`, `no-this-assignment`, `prefer-number-coercion` (`parseInt("12px")` is 12), `prefer-keyboard-event-key` (`keyCode` is deprecated), `error-message`, `require-array-join-separator`, `require-number-to-fixed-digits-argument`, `no-useless-error-capture-stack-trace`.
- **Added, dead code**: `no-length-as-slice-end`, `no-unnecessary-array-flat-depth`, `no-unnecessary-array-splice-count`, `no-useless-collection-argument`, `no-useless-switch-case`, `no-zero-fractions`, `no-lonely-if`, `no-unreadable-iife`, `require-module-attributes`, `prefer-logical-operator-over-ternary`, `prefer-default-parameters`.
- **Added, modern APIs**: `prefer-array-find`, `prefer-array-flat`, `prefer-includes`, `prefer-regexp-test`, `prefer-negative-index`, `prefer-string-trim-start-end`, `prefer-code-point`, `prefer-date-now`, `prefer-math-min-max`, `prefer-math-trunc`, `prefer-modern-math-apis`, `prefer-object-from-entries`, `prefer-prototype-methods`, `prefer-bigint-literals`, `prefer-blob-reading-methods`, `prefer-response-static-json`, `prefer-modern-dom-apis`, `prefer-dom-node-remove`, `prefer-dom-node-text-content`, `prefer-classlist-toggle`, `prefer-event-target`, `prefer-class-fields`.
- **Added, consistency**: `consistent-assert`, `consistent-date-clone`, `consistent-existence-index-check`, `consistent-template-literal-escape`, `escape-case` (pairs with `no-hex-escape`), `prefer-export-from` (off for the vendored shadcn files), `prefer-module`, `no-process-exit` (Effect's `runMain` owns exit), `no-anonymous-default-export`, `no-static-only-class`.
- **Left out, fights Effect**: `throw-new-error` (flags every call to an `…Error` function, so every `Schema.TaggedError<X>()(…)` class), `no-array-method-this-argument` (reads the function in data-first `Effect.flatMap(CurrentUser, f)` as a `thisArg`), `no-array-callback-reference` (point-free `map(f)`), `max-nested-calls` (pipes and Schema composition nest), `no-useless-undefined` (`Context.Reference`'s `defaultValue: () => undefined`, `Effect.succeed(undefined)`), `no-null` (`Option.getOrNull`, React), `no-array-reduce`, `custom-error-definition` (errors are `Schema.TaggedError`).
- **Left out, fights React or JSX**: `no-nested-ternary`, `prefer-ternary`, `prefer-global-this` (`window` in browser code), `explicit-length-check` (taste; shadcn uses `!x.length`), `no-negated-condition`, `no-document-cookie`.
- **Left out, taste or redundant**: `no-array-for-each`, `prefer-spread`, `switch-case-braces`, `switch-case-break-position`, `no-await-expression-member`, `explicit-timer-delay`, `relative-url-style`, `prefer-type-error`, `prefer-set-has`, `prefer-query-selector`, `prefer-dom-node-dataset`, `no-immediate-mutation`, `no-unreadable-array-destructuring`, `import-style`, `no-instanceof-array` (`nkzw/no-instanceof` bans it), `prefer-reflect-apply` (contradicts `anti-slop/no-reflect-apply`), `no-useless-iterator-to-array` (nursery).
- **Left to oxfmt**: `number-literal-case`, `empty-brace-spaces`, `no-console-spaces`. A formatter owns these, and `number-literal-case` wants upper-case hex digits.
