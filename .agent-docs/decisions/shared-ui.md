# One vanilla shadcn package shared by the examples and `www` (human asked)

- `examples/.shared/ui` (`@examples/ui`, private) is the only UI kit. `examples/tanstack-start`, `examples/nextjs`, `examples/react-router` and `www` all depend on it with `workspace:*`; no app has its own copy of a component.
- **Vanilla shadcn**: every component, hook and util in it comes from the shadcn CLI, all of them (`shadcn add --all`), and none is hand-edited. To bump shadcn or pick up registry changes, re-run the CLI at the latest `shadcn` and commit what it writes; never patch a generated file.
- **The CSS is the one exception** (human): `src/styles/globals.css` may change for this project's branding: theme variables, colours, fonts, radius. Nothing else in the package is edited by hand.
- Setup follows raf-query's `@examples/ui`: Base UI rather than Radix (`style: base-nova`), `iconLibrary: lucide`, Tailwind CSS v4 with `cssVariables`, `components.json` aliases pointing at `@examples/ui/{components,hooks,lib}`, and `exports` for `./globals.css`, `./components/*`, `./hooks/*` and `./lib/*`. Versions are the latest at install time ([latest-dependencies.md](./latest-dependencies.md)).
- Anything that isn't shadcn goes in `examples/.shared/kit` (`@examples/kit`): the logo, the issue tracker's shared markup, theme providers, a code highlighter for `www`. raf-query keeps `lib/highlighter.tsx` and `hooks/use-highlighted-code.ts` inside its UI package; here they belong in the kit.
- `.oxlintrc.json` already has raf-query's block that relaxes the rules generated shadcn code breaks, so generated files lint without edits.
- **Built in the examples step, not the skeleton** (agent): until an app imports it, knip reports its dozens of dependencies and exports as unused, and the TanStack Start example is its first consumer. The examples worker creates it with `pnpm dlx shadcn@latest init` then `add --all` in `examples/.shared/ui`, in a commit of its own containing only CLI output (plus the branding CSS in a follow-up), so the history shows the components unedited.
