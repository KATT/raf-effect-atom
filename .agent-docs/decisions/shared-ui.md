# One vanilla shadcn package shared by the examples and `www` (human asked)

- `examples/.shared/ui` (`@examples/ui`, private) is the only UI kit. `examples/tanstack-start`, `examples/nextjs`, `examples/react-router` and `www` all depend on it with `workspace:*`; no app has its own copy of a component.
- **Vanilla shadcn**: every component, hook and util in it comes from the shadcn CLI, all of them (`shadcn add --all`), and none is hand-edited. To bump shadcn or pick up registry changes, re-run the CLI at the latest `shadcn` and commit what it writes; never patch a generated file.
- **The CSS is the one exception** (human): `src/styles/globals.css` may change for this project's branding: theme variables, colours, fonts, radius. Nothing else in the package is edited by hand.
- Setup follows raf-query's `@examples/ui`: Base UI rather than Radix (`style: base-nova`), `iconLibrary: lucide`, Tailwind CSS v4 with `cssVariables`, `components.json` aliases pointing at `@examples/ui/{components,hooks,lib}`, and `exports` for `./globals.css`, `./components/*`, `./hooks/*` and `./lib/*`. Versions are the latest at install time ([latest-dependencies.md](./latest-dependencies.md)).
- Anything that isn't shadcn goes in `examples/.shared/kit` (`@examples/kit`): the logo, the issue tracker's shared markup, theme providers, a code highlighter for `www`, and the site footer with the "Powered by Vercel" badge every app shows ([powered-by-vercel.md](./powered-by-vercel.md)). raf-query keeps `lib/highlighter.tsx` and `hooks/use-highlighted-code.ts` inside its UI package; here they belong in the kit.
- `.oxlintrc.json` already has raf-query's block that relaxes the rules generated shadcn code breaks, so generated files lint without edits.
- **How it was generated** (agent): `shadcn init` and `apply` refuse a package with no framework, so `components.json` is written by hand (shadcn's manual installation), and the CLI writes everything else: `pnpm dlx shadcn@latest add --all -y`, then `add index utils sonner -y`, which `--all` skips without `init` (the base style's CSS and dependencies, `lib/utils.ts`, sonner). The CLI's versions are pinned exactly; `recharts` stays at the registry chart item's pin (3.8.0). To re-check the package is vanilla, run the same commands with `-o` in a scratch copy, format it with the repo's `.oxfmtrc.json`, and `diff -r` against `src` (only `globals.css` differs).
- **Branding** (`globals.css`, its own commit): grays tinted with the logo tile's hue, the orbit's violet as the primary, its teal as the focus ring and first chart colour, one `light-dark()` palette, and raf-query's `dark` variant (system theme unless `<html>` has `dark` or `light`).
