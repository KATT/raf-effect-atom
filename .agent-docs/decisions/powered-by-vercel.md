# "Powered by Vercel" in every deployed app's footer (human asked)

- **Every deployed app shows the badge in its footer**: `www` and each example (`examples/tanstack-start`, `examples/nextjs`, `examples/react-router`), as tRPC does. Vercel's OSS sponsorship asks for it on every page.
- **One copy, in `@examples/kit`** ([shared-ui.md](./shared-ui.md)): a `PoweredByVercel` component rendered by the kit's shared site footer, which every app and `www` use. No app draws its own.
- **Copied from tRPC's v12 site, not redrawn**: [`next/www/src/components/powered-by-vercel.tsx`](https://github.com/trpc/trpc/blob/926132c9bcd57f05fd268c1778b5f9cd8d68f91d/next/www/src/components/powered-by-vercel.tsx), used by its [`site-footer.tsx`](https://github.com/trpc/trpc/blob/926132c9bcd57f05fd268c1778b5f9cd8d68f91d/next/www/src/components/site-footer.tsx). The badge is Vercel's [`powered-by-vercel.svg`](https://github.com/trpc/trpc/blob/926132c9bcd57f05fd268c1778b5f9cd8d68f91d/next/www/public/img/powered-by-vercel.svg) (212×44) inlined as `<svg role="img" aria-label="Powered by Vercel" viewBox="0 0 212 44" fill="currentColor">`, with the black background dropped and the divider drawn in `stroke-border`. It sits in a bordered, muted link that turns `text-foreground` on hover, so it reads on light and dark themes. Keep the path data byte for byte.
- **Link, exactly tRPC's** (human): `https://vercel.com/?utm_source=trpc&utm_campaign=oss`, the same query parameters and values as the `href` in tRPC's `powered-by-vercel.tsx` (also its `docusaurus.config.ts` footer and README). Don't swap in this project's name. A plain link (no `target="_blank"`), like tRPC's v12 footer.
