# File names: kebab-case, PascalCase only for Effect modules (human)

- Human: "I get we're using effect style for effect services etc, but it's really ugly otherwise and looks forced". Files are kebab-case, as in raf-query (`use-atom-result.ts`, `hydration-boundary.tsx`, `error-boundary.tsx`, `internal/failed-reads.ts`).
- **PascalCase only where the file is an Effect-style module**: one imported or re-exported as a namespace (`export * as Loader from "./Loader.ts"`, used as `Loader.make`), or an Effect service, Layer or Schema module. Here: raf-effect-atom's `Hydration.ts`, `Loader.ts` and `RequestRegistry.ts`; the contract's `Authorization.ts`, `Issue.ts`, `IssueErrors.ts`, `IssueRpcs.ts` and `Latency.ts`; the backend's `Authorization.ts`, `IssueHandlers.ts`, `Latency.ts` and `RpcRoutes.ts`; the db's `Issues.ts`. Components, hooks, framework adapters (`rsc.ts`, `react-router.ts`, `tanstack-router.tsx`), entries (`index-react-server.ts`) and internal helpers are kebab-case, whatever they export.
- **Tests and type tests** mirror the module they cover (`Loader.test.ts`, `use-atom-result.tst.tsx`). A second word for the environment goes after a dot: `rsc.react-server.test.tsx` runs in the `react-server` Vitest project.
- **Enforced** by `unicorn/filename-case` in `.oxlintrc.json`: kebab-case on `packages/*/{src,test,typetest}/**` and `examples/.shared/*/src/**`, then a pascalCase override listing the Effect modules above. A new Effect module is added to that list. The rule reads only the part before the first dot.
- **Not enforced**: framework route files (`__root.tsx`, `$issueId.tsx`, `page.tsx`) and `routeTree.gen.ts`, the shadcn CLI output in `examples/.shared/ui`, config files. App code in `examples/*`, `www/` and `tooling/*` is kebab-case already.
- Lost: Effect's PascalCase for every library file, which read as forced on components and hooks (they aren't namespaces) and differed from raf-query. Also lost: kebab-case for the Effect modules too. They're used as `Loader.make`, so a file named after its namespace matches how it reads, and Effect's own source in `.repos/effect`.
